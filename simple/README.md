# Express Hello World

Source: https://github.com/render-examples/express-hello-world

Use Node 24.21.0, run `npm ci`, then `npm start`. The local app listens on http://127.0.0.1:3012. Set `HOST=0.0.0.0` for the proposed Render web service and use its supplied `PORT`. See the parent README and render.yaml for reviewed deployment settings and pending approval.
