# Activity suggestions

Source: https://github.com/Codecademy-Curriculum/deploying-full-stack-with-render-sample

Use Node 24.21.0. Copy `.env.example` to a private `.env` and set DATABASE_URL for the dedicated database. Run `npm ci`, `npm --prefix client ci`, `npm run build`, then `npm start`. The original React interface is served at http://127.0.0.1:3013. Startup applies schema.sql before serving requests.

See the parent README and render.yaml for the deployment settings, verified free-tier terms, source corrections, and pending approval.
